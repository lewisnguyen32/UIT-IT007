# Chương 1 — Kết quả và điểm cần ôn

Mốc hiện tại ở [memory.md](../memory.md); bài soạn ở [mục lục Ch1](../output/chuong-1/README.md). Bốn mục chính 1.1–1.4, 1.2 mở rộng giữ riêng.

- Mục 1.2: câu tự soạn đã trả lời và chữa; nhầm kernel với kernel mode: [CS-C01-001](cau-sai/chuong-1.md).
- Mục 1.4: câu tự soạn về mode bit, trả lời 0 — đúng theo quy ước nguồn (C01 trang PDF 52–53); đã chữa.

- Câu tự soạn 30/10/2026: device driver — driver đúng; interrupt — đúng nhưng người dùng đoán. Các câu cần ôn: [CS-C01-002 đến 004](cau-sai/chuong-1.md); CS-C01-001 đã đúng lại.
- Câu tự soạn 31/10/2026: interrupt — đúng; volatile nhận diện đúng nhưng sai chính tả, xem [CS-C01-002](cau-sai/chuong-1.md).
- Mục 1.3: câu tự soạn về symmetric multiprocessing cần ôn: [CS-C01-005](cau-sai/chuong-1.md).
- Câu tự soạn 31/10/2026: `bus` và `cache` — đúng (C01 trang PDF 14, 22); đã chữa. Volatile, timer và symmetric đã đúng lại; xem [sổ câu sai](cau-sai/chuong-1.md).
- Câu tự soạn 31/10/2026: mode bit ở user mode `1`, bộ đệm `buffer` — đúng (C01 trang PDF 52, 15); multiprogramming đã đúng lại: [CS-C01-003](cau-sai/chuong-1.md).
- Câu tự soạn: nhân `kernel`, bộ nhớ bay hơi `volatile`, device `driver`, đa chương `multiprogramming`, mode bit kernel mode `0` — đều đúng, đã chữa (C01 trang PDF 12, 15, 21–23, 48, 52–53).
- Câu tự soạn: `bus`, `cache`, `timer`, `symmetric`, `asymmetric` — đúng, đã chữa (C01 trang PDF 14, 22, 36–37, 55).
- Câu tự soạn: `middleware`, `controller`, `clustered`, `availability` — đúng; `involatile` cho nonvolatile memory chưa đúng thuật ngữ [CS-C01-006](cau-sai/chuong-1.md) (C01 trang PDF 12, 14–15, 22–23, 40–41).
