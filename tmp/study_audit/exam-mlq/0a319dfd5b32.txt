#include <unistd.h> 
int x = 20;  
int main() 
{ 
int i; 
printf("hello\n"); 
int f = fork(); 
if (f < 0) { 
printf("%d\n", f); //in ra một số nguyên 
fork(); 
} 
for (i = 0; i <= 2; i++){ 
int k = fork(); 
printf("%d\n", f + i); 
if (k == 0) 
fork(); 
else  
   printf("hi\n"); 
} 
printf("hi\n"); 
return 0; 
}

bảng sau: 
Process Arrival Time Burst Time Priority 
P1 2 11 1 
P2 0 8 4 
P3 7 5 5 
P4 9 10 3 
P5 13 6 2

trung bình khi thực hiện các giải thuật định thời sau: 
a) Round Robin với quantum time = 6 
b) Preemptive Priority (độ ưu tiên 1 > 2 > 3 …)
